# Button

Botón de MarkDaun en cuatro variantes; solo un primario por vista.

- **Primario** (`gold` / `on-gold`, Geist Bold): la acción principal de la pantalla. Oro sólido con texto Azul Marino, nunca blanco. Hover `gold-strong`.
- **Secundario** (*ghost* con contorno `line-strong`): alternativas; no compite con el Oro.
- **Fantasma** (`ink-muted`): acciones de barra de herramientas y cancelar.
- **Destructivo** (`danger` sobre fondo neutro): nunca relleno rojo.

Texto en estilo `label` (Geist 500 13px), radio `radius-md` (6px), padding `space-2`×`space-4`, sin sombra, foco con `focus` a 2px.
