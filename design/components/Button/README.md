# Button

Botón de MarkDaun en cuatro variantes; solo un primario por vista.

- **Primario** (`daun` / `on-daun`): la acción principal de la pantalla.
- **Secundario** (`surface`, borde `line-strong`): alternativas.
- **Fantasma** (`ink-muted`): acciones de barra de herramientas y cancelar.
- **Destructivo** (`danger` sobre fondo neutro): nunca relleno rojo.

Texto en estilo `label` (Geist 500 13px), radio `radius-md`, padding 8×`space-3`, foco con `focus` a 2px.
