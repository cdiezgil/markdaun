# Wikilink

Cómo se ven los enlaces entre notas, las etiquetas y el resaltado en la vista renderizada.

- `[[Enlace]]` existente: `daun`, subrayado sólido de 1px, peso 500.
- Enlace roto (la nota no existe): `amber` con subrayado discontinuo, para distinguirlo también sin color.
- `#etiqueta`: chip `sap` / `on-sap`, radio `radius-sm`.
- `==resaltado==`: fondo `mark`, texto `ink`.
- Contador de backlinks: `radius-pill`, `ink-muted` sobre `surface-sunken`.
