# Loader

Progreso indeterminado con la textura de **líneas diagonales** de cdiezgil, que simboliza el procesamiento de datos.

- Úsalo para la indexación del segundo cerebro, la sincronización con GitHub y la transcripción de notas de voz.
- Barra de 8px de alto, radio `radius-sm`, fondo `surface-sunken`, textura `--texture-diagonal` desplazándose a 11px por cada 0,6s.
- Con `prefers-reduced-motion` la textura queda quieta.
- Acompáñalo siempre de un texto en `caption` que diga qué está pasando («Indexando 120 de 1 101 notas»).
