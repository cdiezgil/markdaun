# Editor

El lienzo de escritura: Markdown fuente en Geist Mono 15/26, con la sintaxis atenuada para que el contenido mande.

- Fondo `bg`, cabecera `surface-sunken` separada por `line`.
- Marcas de sintaxis (`#`, `**`, `[[ ]]`, `>`) en `ink-muted`; el contenido en `ink`; el texto de enlaces en `daun`.
- Medida máxima `measure` (68ch), padding `space-6` × `space-8`.
- Selección `selection`; cursor en `daun`, 2px.
