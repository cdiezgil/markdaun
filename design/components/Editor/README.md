# Editor

El lienzo de escritura: Markdown en Geist Mono 15/26, con la sintaxis atenuada para que el contenido mande.

- Fondo `bg`, cabecera `surface-sunken` separada por `line`.
- Marcas de sintaxis (`#`, `**`, `[[ ]]`, `>`) en `ink-muted`; contenido en `ink`; texto de enlaces en `daun` (Oro en Marino, Oro profundo en Técnico).
- Medida máxima `measure`, padding `space-6` × `space-8`.
- Selección `selection`; cursor en `daun`, 2px.
- H1 renderizado en Geist Bold (`reading-h1`); cuerpo de lectura en Geist Light 17/28.
- Bloques de código sobre `surface` (Marino: `#1A2235`) con un filete de 2px en `daun` a la izquierda.
